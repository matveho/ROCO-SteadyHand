# First live wrist images

Both images are RGB captures from the successful combined camera boot. Original resolution: 1920 x 1536.

- `wrist_a.png`: **right wrist**, identified by the onsite operator after viewing both images.
- `wrist_b.png`: **left wrist**, identified by the onsite operator; board visible.

Startup frames were initially black; saved images were captured after nonblack frames arrived. Increasing frame IDs were observed. This confirms image acquisition, not calibration or visual servo accuracy. No arm motion was commanded.
