# Local data

Keep recordings, robot models, SDK archives, and selected demonstrations here.
Use descriptive subfolders such as `recordings/vega/`, `models/`, and `reference/`.
Record source URL/revision and capture time beside each item. Download only what
we need; do not clone the entire demonstration dataset by default.

Session-specific outputs belong in `../runs/`. Runs and local data are gitignored;
this README stays in Git.
